Python Voice Assistant

Project Description

A beginner-level voice assistant developed using Python. It listens to voice commands and responds by speaking.

Technologies Used

- Python 3.12
- SpeechRecognition
- PyAudio
- pyttsx3

Features

- Greets the user
- Tells the current time and date
- Searches Google using voice commands
- Responds to basic commands
- Handles microphone and speech recognition errors

How to Run

1. Install Python 3.12.
2. Install the required libraries:
   "pip install SpeechRecognition pyttsx3 PyAudio"
3. Run the program:
   "python main.py"
